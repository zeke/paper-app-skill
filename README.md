# paper-app-skill

An [agent skill](https://agentskills.io) for working in [Paper](https://paper.design), the HTML-and-CSS design tool, through the MCP server built into its desktop app.

Paper's MCP server comes with a good guide on design quality and workflow. This skill fills in the rest: quirks of calling the tools from a code-running agent, how to get screenshots when images don't come through, where exports land, how to use custom fonts and local images, how to keep a busy canvas organized, and what the MCP can't do. It's distilled from real design sessions: slide decks, homepage explorations, and design-to-code handoffs.

## Install

```bash
npx skills add zeke/paper-app-skill
```

The Paper desktop app has to be running for its MCP server to respond.

See [AGENTS.md](AGENTS.md) for contributor notes.
